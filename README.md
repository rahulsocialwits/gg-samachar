# GG Samachar

Gujarati-first bilingual digital news platform.

## Features
- Gujarati + English article presentation
- Latest/news/category pages
- Weather dashboard ready for weather API
- Share market dashboard ready for market API
- Gujarati calendar / Panchang UI
- Responsive mobile-first newsroom design
- Independent from TechPulse

## Planned automation
RSS / news APIs → duplicate detection → AI rewrite → Gujarati article + English translation → SEO metadata → GitHub publishing.

## Deployment
Static frontend can be deployed on GitHub Pages, Cloudflare Pages, Vercel or Hostinger. Dynamic Worker/API features should use a separate Cloudflare Worker and D1 database for GG Samachar.

## Important
Demo content in the repository is placeholder content, not live news. Connect verified news sources and data APIs before production publishing.
